# SongNote 图标

新版采用内置 imagegen 生成，取代旧版带绿色徽章的图标。最终方向：立体暖黄便签纸、奶油色卷角、三条深灰笔画、透明背景。转换为多尺寸 Windows ICO 与 macOS ICNS 时保留透明通道。

- 母图：`assets/songnote-icon-master.png`。
- 预览：`assets/songnote-icon.png`。
- macOS：`assets/AppIcon.icns`。
- Windows：`windows/assets/SongNote.ico`。
- 重建原生格式：`scripts/generate-icons.sh`。

最终生成提示词：

> Use case: stylized-concept. Asset type: final production desktop application icon for a personal sticky notes app named SongNote, to be exported as macOS ICNS and Windows ICO. Create ONE elegant premium app icon, square composition, transparent outside the icon. The central icon is a soft squircle made from a small stack of warm golden-yellow sticky note paper, with a subtly curled lower-right corner revealing a creamy paper underside. A beautifully restrained 3D material finish, soft bevels, delicate realistic paper edge and soft ambient shadow, polished contemporary macOS desktop icon quality. On the yellow top sheet, just three bold short embossed charcoal horizontal writing strokes with balanced proportions; the first shorter than the second, third shorter again. Simple confident silhouette legible at 16 and 32 pixels, dominant butter-yellow paper, cream curl, charcoal strokes. Centered front view with only slight depth, no distracting perspective. Fill about 84 percent of square canvas with comfortable equal transparent margins. No separate background tile behind the note, no circle badge, no sync arrows, no pens, no plants, no letters, no words, no logos, no frames, no watermark, no surrounding objects. Aim for an iconic and tasteful actual desktop icon, not a flat clipart illustration and not a shiny plastic toy.
