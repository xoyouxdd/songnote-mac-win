# Mac 1.2.2 本机验证

日期：2026-10-03。基线：GitHub `d70a73d`，本地分支 `codex/mac-1.2.2-validation`。运行环境：Apple Silicon、macOS 27.0.1、Swift 6.4.0；应用仍以 Swift 5 模式编译，最低部署版本 macOS 13。

## 本轮修复

附件滚动文档使用非翻转坐标及手工尺寸，展开时初始视口可能落在空白区域，文档宽度也未随视口正确调整。实际原生窗口确认了空白问题。改为从顶部排列的文档视图，并通过约束跟随滚动视口宽度，附件操作行保持 24 pt 高度。新增检查覆盖初始可见附件、文档宽度、内部控件边界和长列表滚动。

同时补齐动画完成回调与减少动态处理的主线程标注，修正动态重做选择器的编译警告。最终构建零警告、零错误。

## 验证结果

- 服务端 8 项测试通过；Swift 模型测试通过，包含旧状态、冲突、草稿、冻结载荷、附件和输入法覆盖状态。
- 正式应用的 21 项 AppKit 布局检查通过，包括窄窗、单/双列、冲突及保存失败提示、附件折叠/展开和本轮回归检查。
- 本机 HTTP 回环与原生运行检查通过 60 条断言：附件导入、零字节、大小限制、上传去重、远端下载、hash/大小错误不覆盖目标；附件空正文持久化；服务已接受但响应丢失后的冻结载荷重启重试；后续编辑保留及版本推进；回执保存失败恢复；旧服务的附件保留及文字独立同步；12 个附件在三种尺寸下滚动；原生 marked-text 提交及附件覆盖状态。
- 回环工具仅将 `Store` 的预览初始化目录与配置注入私有测试路径，其余生产同步/持久化方法直接执行。验证工具、虚构文件和状态位于被 Git 忽略的 `private/mac-validation/`；未用真实便签进行编辑或故障注入。
- 独立原生验证应用实测系统打开窗口、选择虚构文件、添加后计数变化、系统另存为与取消、滚动到首尾；另存文件字节与源文件一致。
- 正式应用 ad-hoc 签名验证通过。

## 本机安装

已正常退出旧 1.1.0 应用，将通过验证的 1.2.2 安装到 `/Applications/SongNote.app`，并重新启动。旧应用、退出前后数据及偏好备份保留在被 Git 忽略的 `private/mac-deploy-1.2.2-*`，JSON 文件只允许当前用户读写。

安装后二进制、Info.plist 和图标与构建产物一致，签名有效，进程与列表窗口正常，界面显示已同步且无保存失败。本机原有 device_id、便签正文、颜色、置顶、删除和冲突属性保持一致；附件元数据与服务器快照一致，待同步操作为零。服务 health 为兼容的 1.2.1，并声明附件能力。本轮只更新 Mac 本机应用，没有更新服务器或 Windows，也没有 Git 提交或推送。

## 验证边界

回环测试和服务器快照检查不代表真实 Windows/Mac 双端附件互传验收。真实中文输入法候选操作、真实多屏、完整 VoiceOver、开机启动注册以及最低 macOS 13 实机仍未验证。marked-text 检查是原生文本控件程序化操作，不等同于真实输入法测试。
