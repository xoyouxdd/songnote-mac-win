# SongNote 界面规范

更新：2026-10-01。方向已确认：先优化 Mac，再按本规范实现 Windows。以原生桌面控件承载纯文本便签；列表便于找到内容，独立窗口尽量把空间留给书写。

## 颜色与尺寸

使用 sRGB，Mac 单位为 pt，Windows 为 DIP；坐标不跨设备同步。两端采用固定浅色纸面与深色文字，避免系统深色模式使六色混成灰色。系统高对比模式需另做可读性验证。

| Token | 值 | 用途 |
| --- | --- | --- |
| ink | `#303633` | 正文、标题、选中边框、实心按钮 |
| muted | `#596159` | 预览、时间和普通状态，字号至少 11 |
| paper | `#F6F5F0` | 列表窗口背景 |
| success | `#457A63` | 同步成功状态点 |
| yellow | `#FFF5C9` / `#E8B931` | 纸面 / 色条与色块 |
| green | `#E0F0D6` / `#5BAE6E` | 纸面 / 色条与色块 |
| blue | `#DBEBFA` / `#4A90D9` | 纸面 / 色条与色块 |
| pink | `#FAE0E8` / `#E07597` | 纸面 / 色条与色块 |
| purple | `#EDE0FA` / `#9B7BD8` | 纸面 / 色条与色块 |
| gray | `#EDEDE8` / `#92928A` | 纸面 / 色条与色块 |

侧条使用完整色值，不再和深灰混色；卡片直接使用纸面色，不再兑白。色条、圆点用作颜色识别，文字始终使用 ink/muted，不把浅色圆点当作唯一状态信息。

| 项目 | 规格 |
| --- | --- |
| 列表标题 / 卡片标题 | 13 半粗 / 15 半粗 |
| 预览 / 提示 | 13 / 11，单行省略，完整状态可用提示文字读取 |
| 正文 | 16，Mac 行间距 5；Windows 中文字体使用系统回退，行高约 1.3 倍 |
| 卡片 | 高 84、间距 8、圆角 8、侧条宽 4；内边距左 14、右 12 |
| 列表内容 | 左右 16；搜索高 28；搜索、筛选、列表之间间距 8 |
| 按钮 | 圆角 6；Mac 标题栏图标 22×22，Windows 图标点击区至少 28×28 |
| 窗口 | 列表默认 460×710、最小内容 360×360；便签默认 380×420、最小内容 280×240 |

图标沿用 `assets/AppIcon.icns` / `windows/assets/SongNote.ico`，不重新生成。ICO 保留 16/24/32/48/64/128/256 七种尺寸。

## 列表布局

标题与新建图标并入原生标题栏；移除大图标、重复副标题。内容依次为搜索、全部/置顶筛选、卡片、底部状态。默认高度应能完整看到至少六张卡片。

滚动视口宽度小于 620 时单列；达到 620 时双列，按行从左到右排列。列间距 8，列宽为 `(视口宽度 - 列间距) / 2`。最后一行不足两张时保留一个完整卡片位置，文档高度按行数计算，任何宽度下右侧圆角及末行不得被裁切。

卡片包含标题、正文一行预览、时间与置顶/冲突/待同步提示。保留键盘选择的深色边框；状态更新复用按便签 ID 管理的卡片，避免同步时丢焦点。编辑窗口正处于正文输入时保留列表现有顺序；离开编辑或关窗后按置顶、修改时间重排。新增条目仍可出现，筛选即时生效。时间提示至少每 30 秒刷新，跨午夜从“今天”变为“昨天”。

## 独立便签

标题栏只保留新建、返回列表、列表置顶、更多四个图标。列表置顶采用空心/实心图钉及深色选中底，选中状态同时提供可访问名称。移除第二行工具与无用的便签总数。

“更多”顶部是一排六色圆点，选中圆点有勾选和描边；每个圆点有颜色名称与辅助功能标签，另提供带色点和中文名称的原生子菜单供键盘使用。下方为“总在最前（仅本机窗口）”和“删除便签…”。“列表置顶”同步到两端，“总在最前”只修改当前设备的窗口层级。

正文内边距横向 16、纵向 12，可调整窗口尺寸。正常底部只显示一行状态和立即同步图标；完整提示解释本机保存和服务器接收是两个阶段。保存失败时优先显示红色“本地保存失败，请勿退出”，同步暂停；立即同步先重试本地保存。离线或配置/响应异常显示文字和橙色，不能仅靠色点区分。另一台电脑仍需运行应用并联网，不把服务器接收描述为对端已显示。

冲突提示位于正文上方且不被下一次同步覆盖：副本显示“这是冲突副本”并可查看原件，原件删除/缺失时说明原因；删除遭拒显示“另一端有新内容，已保留”，用户点“知道了”后才清除。副本同时遭拒删除时，先显示删除提醒，确认后继续显示副本来源。列表底部提供查看提醒入口。

## 操作与保存

- Mac 快捷键：⌘N 新建、⌘L 列表、⌘F 搜索、⌘R 同步、⌘W 关窗、⌘Q 退出。Windows 统一用 Ctrl 对应业务快捷键，退出用托盘菜单。
- 卡片按下选中，鼠标松开且仍在卡片内才打开；拖出取消。方向键移动、Enter/Space 打开；双列上下按列移动，目标不存在时留在当前卡片。搜索框按下方向键进入第一张卡片。
- 卡片右键可直接置顶、换色、删除；动作重新读取目标 ID 对应的当前内容，删除需确认。
- 新建空白便签先作为本机草稿保存，不提交服务器；第一次实际正文、颜色或列表置顶改变后才入同步队列。未编辑空草稿关窗/退出时丢弃。已有空便签、编辑后清空的便签和另一端创建的空便签保留。
- 中文输入法候选文字不保存、不同步，也不被后台刷新覆盖；正式选字后保存。关窗/退出时取消尚未确认的候选，保留已提交文字。输入期间远端更新时保留输入开始的版本，提交后交由服务器保留冲突副本。仅接受本机已确认的成功回执来推进该基准，删除拒绝不能自动推进。
- 保留本机窗口位置、尺寸与打开状态。没有历史位置的新窗相对上个窗口向右下错开 24；恢复窗口前夹入当前显示器工作区，兼容负坐标及外接屏断开。
- 关闭列表后仍在菜单栏/托盘运行。菜单列出置顶便签，并提供开机启动；启动项勾选反映系统实际状态，失败或等待批准时明确说明。开机启动默认关闭，只有用户点击才更改。

## 动效

统一使用约 140–220ms 的轻量动效，不让每次后台轮询制造闪烁。尊重系统减少动态设置；开启时直接显示最终状态，并停止正在进行的动效。系统设置变化也应立即更新。

| 场景 | 动效 |
| --- | --- |
| 卡片悬停 | 纸面微亮、边框加深 |
| 增删和重排 | 卡片淡入/淡出，位置平滑移动；正在输入时不跳顶 |
| 同步 | 主动同步或提交编辑时图标旋转，完成状态点闪一次；无变化轮询保持安静 |
| 换颜色 | 纸面底色在 180ms 内过渡 |
| 打开新窗口 | 轻微放大淡入；已有窗口直接激活 |
| 列表置顶 | 空心/实心切换并轻微弹性反馈 |
| 删除 | 140ms 淡出，余下卡片收起；退出中的卡片不再响应操作 |
| 便签不在前台 | 标题栏工具淡到 55%，重新激活恢复 |

## 验证边界

Mac 源码在 Windows 上修改，语法解析与源码复核不替代 Swift/AppKit 编译。`--check-layout` 使用七张内存样例，检查单列/双列、奇数末行、标题栏、最窄便签、冲突提示和保存失败，不读取真实配置、不存文件、不连服务器。Mac 必须执行模型测试、构建、原生布局检查和真机输入/动画验证，清单见 [续作与验收](UI_OPTIMIZATION_HANDOFF.md)。Windows 已有 WPF 首版可执行程序并完成本机定向检查，详见 [Windows 验证记录](../windows/VALIDATION.md)；真实输入法、多屏和双端实机同步尚未验收。
