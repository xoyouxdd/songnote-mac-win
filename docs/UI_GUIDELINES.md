# SongNote 界面规范

Mac 和 Windows 统一采用暖白底色、柔和的六色便签、深灰绿文字和简洁圆角按钮。

- 应用图标：Mac `assets/AppIcon.icns`，Windows `windows/assets/SongNote.ico`。设计为立体暖黄便签纸、奶油色卷角和三条深灰笔画；透明背景，ICO 含 16/24/32/48/64/128/256 像素尺寸。母图为 `assets/songnote-icon-master.png`，由内置 imagegen 生成，重建尺寸和容器格式的命令：`scripts/generate-icons.sh`。
- 列表：应用图标与「我的便签」标题；明显的「新建便签」按钮；标题/正文搜索；「全部 / 置顶」筛选。
- 卡片：柔和底色、细边框、颜色侧条；标题 17px，正文预览 13px，底部显示修改时间、置顶或冲突副本状态；整张卡片可点击打开对应窗口。
- 便签窗口：顶部「便签列表」「＋新建」和总数；第二行颜色、列表置顶、窗口置顶、删除；正文保持足够留白，默认 16px、约 5px 行间距。
- 底部：分开展示本机保存和服务器同步状态，旁边提供「立即同步」。正常、离线、保存失败分别采用中性色、橙色、红色反馈。保存失败禁止继续提交；用户点击同步可以先重试本地保存。
- 窗口默认尺寸：列表约 460×710，独立便签约 380×420；支持调整尺寸，既有窗口位置和便签内容保留。
- 自动保存与自动同步为默认流程，不设置「保存」按钮；「已同步」仅指服务器确认接收，另一台电脑仍需运行应用并联网。
