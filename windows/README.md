# Windows 端代码目录

此目录保留给 Windows 端开发；所有 Windows 项目源码、项目文件、资源和构建脚本放在此处。服务端及 Mac 端已采用同一套 [同步协议](../docs/SYNC_PROTOCOL.md)，Windows 实现必须遵守该协议。

界面与图标遵循 [UI 规范](../docs/UI_GUIDELINES.md)。应用图标已备好：`assets/SongNote.ico`，包含七种原生尺寸。

建议使用 .NET 8+ WPF 原生桌面程序；支持 Windows 10/11。无登录页面，第一次运行读取预置私有配置。

## 实现清单

- 便签列表、正文搜索、新建、单击打开；每条便签单独窗口。
- 每张便签顶部显示「便签列表」「＋新建」和便签总数；点击已有便签激活原窗口，不重复打开。
- 每张便签底部独立显示「已保存到本机」与「等待同步／正在同步／已同步／离线待同步」，并提供「立即同步」。无需保存按钮。
- 「已同步」指服务器已确认接收；另一台电脑需要运行应用并联网才能获取。保存失败必须醒目提示，同步暂停；点击立即同步先重试本地保存。
- 纯文本编辑、自动保存、6 种颜色、列表置顶、删除确认。
- 窗口置顶、尺寸和位置、打开状态只存 Windows 本机。
- 本地数据放 `%LOCALAPPDATA%\SongNote`；设备 ID 固定，每台机器不同。
- 本机便签和持久待同步队列原子写入同一文件/事务，离线可编辑，重启继续提交。
- 首次安装配置 `client-config.json` 的结构参见模板；真实配置通过管理员 SSH/SFTP 从服务器 `C:\便签\private\client-config.json` 获取。私有配置不能提交 GitHub，也不要通过公开链接下载。
- 每 3 秒同步、编辑后延迟约 700ms、请求失败退避重试。标准 HTTPS 校验证书，不允许跳过证书验证。
- 同步请求在途时继续输入、冲突副本 ID 迁移、离线删除遇到远端新编辑，是必须验证的流程。

## 完成条件

用实际 Windows 客户端和 Mac 客户端检查：新建→编辑→颜色→删除两边同步；断网编辑→退出重开→联网补传；两边同时编辑保留两份内容；一个请求期间继续输入不丢字。完成之前不能宣称 Windows 实机互通已验收。

当前目录是开发交接目录，尚无 Windows 可执行程序。请勿改动 macos/；如需扩展字段，先协调协议版本。
